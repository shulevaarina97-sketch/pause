First public version of Pause — somatic micro-reminders from the menu bar.

**Download**
- macOS (Apple Silicon): `Pause-0.1.0-arm64.dmg`
- Windows 10/11 (x64): `Pause.Setup.0.1.0.exe`

**First launch** — the app isn't code-signed yet:
- macOS: System Settings → Privacy & Security → **Open Anyway**
- Windows: SmartScreen → **More info → Run anyway**

**What's inside**
- A 5-second cue over any app every 30 / 45 / 60 minutes, no clicks, never steals focus
- Skips reminders when you're away from the keyboard
- Box breathing 4-4-4-4
